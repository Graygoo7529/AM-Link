# AM-Link 二期协议

2026-10-27 当前协议。公开接口仍只有 Add/Search；完整设计见[根 DESIGN](../DESIGN.md)，工程与真实验证见[本轮实施报告](../docs/doing/2026-10-27-delivery-contract-implementation.md)。尚未部署或通过官方评测。

## Add

`POST /v1/memory/add`：`request_id`、`user_id`、`session_id`、非空 messages（role/content/可选 timestamp）。成功回传 `success=true` 和三个原样 ID。

同用户串行、同 `(user_id, request_id)` 与 payload 幂等。先在事务外准备原文、最低 episode 和必要 embedding，再在一个短事务中提交原文、Working 范围、不可变 episode、词法/向量索引及成功响应凭据。事务提交前失败，本轮材料不生效；未知提交结果不能宣称已撤销。提交后响应丢失可用同 ID 重放恢复，同 ID 不同内容拒绝。

接收成功后，按积累、会话边界或相关新证据开展请求内有界 Reflection。整理失败/未完成不取消接收成功；未通过检查的草案不成为记忆。成功重放不重复任何模型调用或整理。必要接收失败的请求重投时重新准备必要工作，无内部网络重试、后台补偿或自动重建。

明确授权遗忘的来源定位和屏蔽属于必要接收：模型辨别指令、查找真实来源，原子屏蔽完整来源消息及所有依赖节点/索引。引述不视为授权，定位失败不伪称已执行。其它材料仍可保留 Working，依靠最低 episode 立即检索。

默认总期限1740秒含锁等待；模型单次最多120秒，整理阶段最多提前5秒收束。字段不扩充为整理完成承诺，内部完成进度通过观测记录。

## Reflection 内部协议

数据库版本3、冻结计划v3；旧数据库显式拒绝，新实验新库，不静默迁移。Workspace 阅读格式仍为v2。

每个原文段 `pN` 直接填写自然问题和必要背景位置，完全相同问题聚合成组，不再交叉引用动态 groups 数组。主归属完整唯一，背景共享不算已处理。来源坐标和正文版本保持不变。

节点草案、关系草案、局部 patch 和联合审查由程序推进，不暴露纯 commit/validate 模型动作。审查为必填 `uN` 键到决定的对象，支持正文/日期/来源修订、撤销节点与边；重复键、缺键和数组替代对象拒绝。`remaining_work` 只列修订后仍缺的具体工作，合法修订保存为草案继续补读或 patch。所有提案撤销且确实无增量时才可用 `no_change_reason` 完成 episode_only。

关系必须与最终节点正文相符。保留已修改端点的边须重新确认；supersedes 需给出可在所选原文核对的 replacement_quote。逐字支持不等于语义正确，仍需研究核验。

图/向量/状态/每组完成凭据在一个事务提交；一个失败组不阻塞其它可处理组，连续水位不能跨未完成缺口。草案保存相关旧节点版本，版本变化时不恢复陈旧草案。相关证据没有变化时，不因另一个 Add 到来而原样重做失败组；成功请求重放永不触发整理。

## Search

`POST /v1/memory/search`：`user_id`、`query`、`top_k`、可选 `options`。返回 `data`，各项含 id/content/score/created_at，数量不超过 top_k。内容是证据，不能生成最终答案。

```text
新语境 + question
→ 可选 LLM 查询扩展 → 每分支 BM25/embedding → 合并
→ 候选多时 Select（question + 可读原文卡，筛选并排序）
→ 模型选择 Inspect / Backlink / Stop，多跳更新语境
→ 确定性证据组装箱
```

Search 只读结构化 MemoryItem，包括最低 episode；不读 Working、不触发 Reflection、不共享 Add 的内部 loop。Inspect 返回正文与正向引用，Backlink 返回带叙事的反链引用，候选过多时 Select。每步在临时语境中完成后整体合入；失败步骤的引用、范围、路径和覆盖说明不能泄漏到最终输出。

Select按包含工具定义的80000字符输入预算分页；窗口数量随候选、原文及分支贡献变化，不固定每ref四段。所选范围持续进入语境与装箱，预算遗漏明确记账。coverage为待核验的模型导航说明，不代替原句。合法空选择是正常空集，非法输出是错误。

装箱保持候选相对顺序并组合实际图路径，score仅为返回次序。已完整交付来源的纯重复episode不另占名额；闭合不足不输出该关系陈述。来源、角色、时间和片段范围保留，完整来源/路径闭合/足够回答分别记录，最后一项未经验证即未知。

## 错误与完成状态

| 阶段 | 对外与内部结果 |
| --- | --- |
| Add 必要 embedding/索引/提交失败 | 返回错误；已确认回滚才称无新材料 |
| Add 原子接收后 Reflection 失败 | 返回200；子错误、未完成组和草案保留 |
| Search 首次 Query/必要 Select 失败 | 返回错误，不能当正常空集 |
| Search 后续模型/协议/预算失败 | 丢弃本步变化；可返回最后完成语境的合法证据，标注内部 partial |
| Search 数据库/完整性失败，或有候选却不能合法装箱 | 返回错误 |
| 正常无候选或合法空 Select | `data=[]` |

内部错误保留标准 span；父请求返回200不改变子步骤 error。网页展示接收与整理状态、完成/未完成组、局部停止原因；历史缺字段显示未知。HTTP和native共用Engine判定，服务默认不采集内部轨迹。
