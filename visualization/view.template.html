    常见词与编码怎么看
    record / persona
    一条研究记录 / 一个模拟人物；一条记录可带多段历史和多道问题。
    session / turn / probe
    一次会话 / 一条发言 / 用来检测记忆能力的问题。来源单元也可能是事件或事实，并不总是对话。
    annotation / gold / rubric
    作者提供的标注 / 参考答案 / 逐项评分要求；这些不是方法自己记住的内容。
    evidence / has_answer
    证据位置 / 片段是否被标为含答案；有标记不代表没有歧义，也不代表整条是用户事实。
    JSON 与转义字符
    花括号组织字段，方括号组织列表；引号界定字符串。反斜线 n 表示换行，反斜线 u 加编码表示 Unicode 字符；不是原话中多出的知识。
    null / false / []
    未提供值 / 明确为否 / 空列表。它们不能互相替代。下方“样本与标注”会解开容器，保留原始写法供核对。
    top-k / cutoff
    最多返回几条 / 只允许看到哪个时间之前的数据。召回片段不等于回答正确。
