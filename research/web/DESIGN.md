# 研究页面设计

2026-10-30 已实施。一个入口，五个互相连接的视角：总览、数据与标注、案例链路、真实运行、下一步设计。

## 身份与事实边界

案例使用 dataset + prepared pack + record + task + turn 定位；深入研究额外绑定 run_id + dataset_pack_sha256。运行保留源数据/请求计划/轨迹指纹，每个步骤绑定记录、问题、请求、父步骤和材料哈希。未知绑定、缺材料或坏指纹直接拒绝构建，不补造观测。

理论链路回答“应当记住、检索和组合什么”；真实观测回答“模型实际看见和选择什么”。原评分与Codex复核分开展示；coverage仅字面来源核对，不能称事实完整度。未来新增运行不自动继承过去的理论验证结论。

## 单页与分片

`research/data/index.html` 包含数据说明、案例catalog、题目索引和研究议题；`runs/<id>.js` 按需载入每份运行全部Add、Search、Answer、Eval与材料，避免同一Add轨迹随每道题重复复制。分片使用本地script载入，兼容file://；无需后端、CDN或fetch跨域。运行数据仍在忽略路径。页面选择不持久化。

渲染不执行任何原文HTML；脚本数据转义 `<` 与行分隔符。嵌入响应只省略向量数值，保留维数和原文件。长文本提供滚动，原始内容不变。数据集样本定位视图可有明确展示省略，真实模型步骤保持完整文本。

## 扩展与评注

新增案例修改唯一catalog；新运行注册即可出现；批次的聚合指标和独立复核由workspace.json引用冻结计划。评注以amlink.note.v1下载，导入前核验运行/数据/轨迹/步骤，导入后追加且可用supersedes修订旧结论。页面不能声称下载等于已经保存到库。

本轮整合不恢复二期语义图或改变生产Add/Search算法。旧页面和模板仅在archive；无第二套活动展示入口。
