# 案例研究

唯一展示入口：[记忆研究室](../data/index.html)。案例真源为 [catalog.json](catalog.json)，供靶场和页面共享，不再维护单独案例网页。

目前36个案例：保留原26个理论案例，新增10个；其中16个案例绑定第三版100题实测并建立深入链路。100题均有回答复核，其余未深入研究的题明确标记，不能当作100份完整理论分析。

从 [16个深入研究](2026-10-30-real-evidence-studies.md) 开始：包括遗漏费用/活动、角色与事件状态、日期精度、遗忘回流、牌局归属、评论引文集合、条件适用、弱偏好标注，以及比例/日期差/配额更新正控制。下一轮问题汇于 [issues.json](issues.json)。

新增案例按 [TEMPLATE.md](TEMPLATE.md) 写明必要事实、原文来源、Add保存、Search组合、Answer边界、反例及验证。catalog的studies绑定具体运行与数据指纹，分别写theory、observed、limits、next_experiment和可定位步骤ID。

早期案例中的方法设想是理论参考，不代表第三版已经实现六类节点或自由BFS。二期方法运行研究与Mem0小实验已移至 [历史研究归档](../../archive/research/20261030-consolidation/cases/)。
