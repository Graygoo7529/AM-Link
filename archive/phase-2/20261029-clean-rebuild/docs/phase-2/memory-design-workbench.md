# 从样本开始设计 AM-Link

日期：2026-10-07。状态：研究建议，尚未实现二期记忆系统。入口为[统一可视化](../../visualization/README.md)与[案例库](../../casestudies/README.md)。

## 首先决定记忆需要保住什么

把一条记忆理解为带来源的可用证据，而不只是短摘要。例如“25:50”需要知道是谁的、哪一场项目、何时得知、取代哪个旧值、原句在哪里；“日本旅行计划”还需要知道是否被允许长期保存。

建议先实现最小的两层：可追溯原文与可检索的派生事实。原文不是永不删除的永久库，遗忘请求应覆盖活动原文、派生记忆、索引和缓存。摘要和关系图都只是可重新解释的派生视图，不要让缺少来源的结论成为唯一记忆。

派生事实的概念字段可包括主体、关系/属性、值、适用时间、来源时间、肯定/否定、引文/本人陈述、有效/已更新/禁止使用，以及 source IDs。字段是设计起点，不要求先实现复杂图数据库或全套实体系统。

## 用具体案例决定机制

| 机制 | 先验证的案例 | 成功证据 | 常见误判 |
| --- | --- | --- | --- |
| 主体与引用归属 | PV01、L03 | 人物身份随记忆和 Search 保留 | 只要关键词相关就是好检索 |
| 时间锚点 | LM02、L02 | 原文日期→事件日期解释→答案上下文可追踪 | 使用当前写入时间代替事件时间 |
| 同属性更新 | LM01、B01 | 新旧值与更新依据连通 | 返回 HTTP 200 就认为更新完成 |
| 未解决冲突 | B02、P02 | 冲突双方可见，回答保留不确定性 | 一律最后写入覆盖 |
| 多跳补齐 | M01、L01 | 所需关系全部返回，缺口可定位 | 第一跳命中就是整题成功 |
| 适度不使用记忆 | LM03、PV02、V302 | 拒答、撤回、当前帮助与长期保存分离 | 空检索就是失败；不记住就是不帮忙 |
| 时间切面与近期反馈 | V301 | 仅使用提问前事件，重复/负反馈语义分开 | 未来标签或 lifetime 信息进 Add |
| 多证据工作任务 | C01、CL-bench | rubric 要求的覆盖维度、引用、排除条件分别检查 | 相关性分数高就满足所有工作约束 |

## Search 先寻找可验证的证据包

建议路径：理解当前问题的实体与约束 → 初步召回 → 检查缺少的主体、时间或关系 → 在有界预算内补齐 → 保留来源并排序 → 交给 Answer。对 M01，第一跳返回最新作者后，下一跳查询其配偶，再查国籍；不能在 Search 中凭常识代答。

可以设置“最多几次扩展、最多多少候选、最终多少字符”的预算，记录每次实际调用与停止原因。是否值得引入 query 改写、关系扩展或重排，需要相同输入和证据预算下的实验；本轮没有证明这些机制已经提高 AM-Link 成绩。

## 最小可观测闭环

沿用 [observability v1](../../benchmark/OBSERVABILITY.md)，不另起一套日志协议。每个问题应能复核：

1. source：给了哪些原文，角色、日期、独立限制是否完整，哪些因时间或遗忘排除。
2. Add：抽取了哪些记忆，来源关联，更新/撤回前后快照；无事实提取与模型依赖失败分开。
3. Search：各轮查询、候选、分数、关系扩展来源、最终选中与淘汰原因。
4. context：Answer 实际看到的文本与顺序，裁剪是否丢掉时间/否定/归属。
5. Answer/Eval：本地诊断的实际回答、支持程度及评分依据；官方 Answer/Eval 仍由主办方负责。

实体与时间解释、旧新版本和选中原因写在 span 引用的 artifact 中，保持 v1 外壳稳定。`links` 已支持 derived_from / supports / contradicts / supersedes；不要把人工理论路径写成实际执行步骤。

## 建议实验顺序

先用这些人工选例校验字段和机制，再用完整用户/历史检验检索。LongMemEval 可比较 Oracle 与 S/M：若 Oracle 仍失败，先查表示或回答；只在长历史失败再查召回与预算。但它们不只是长度干预：Oracle 是按答案会话筛出的条件，必须明确选择偏差。

本轮 BM25 是未调参的本地参照：470 题任一证据 @5 为 373，完整证据 @5 为 262；跨会话子集 121 题分别为 93 与 29。它证明这套诊断能分辨证据缺口，并不证明 AM-Link 或 Mem0 的相对性能。

[Mem0 短片段实测](../../casestudies/mem0-microstudy.md)又暴露三个检查点：日期写进 Add 后仍可能在抽取中丢失；开放建议不应因缺少个性化记忆而一律拒绝；遗忘测试必须先确认目标事实已被保存，否则未见违例不能证明删除成功。更新题答对但旧值并存，也提醒我们分开衡量内部表示与最终结果。

后续比较分别报告来源覆盖、完整链覆盖、回答正确/拒答、归属越界、遗忘违例、延迟、调用与费用。按 persona/context/长期对话整组留出；调过的案例继续保留为回归集合，不冒充未见测试集。
