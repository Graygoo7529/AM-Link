## 目标与边界

保留不可变原文、原子接收、幂等、用户隔离、跨Add小批整理、v4/1024和mini、无内部重试。普通Search一次Select，补充后最多一次最终Select；不加每题规划模型、不恢复自由BFS和复杂图写入。改动直接进入唯一默认方法，不保留默认关闭的备用算法。

模型读到的原文和最终交付范围要一致；导航只是访问原文的理由，不代表事实强度。可见的身份、日期和标题必须有原始依据。标注只用于研究侧，禁止输入方法。

## 具体设计与核对项

### A．可追溯的阅读单位与真实邻接

- [x] 为episode记录所属来源总长度、原文标题／开头锚点、准确范围。通用标题包括Markdown标题、短标签行、带显式编号的标题；无标题时只展示原文开头，不编造事件名。
- [x] 段落／句子单位保持逐字原文；索引片段优先在明确标题前分界。锚点与正文分开标出处，不伪装成连续引用。
- [x] 同一来源只把紧邻范围视为邻居；跨消息按同一会话的实际接收顺序连接，不依赖request_id。所有被遗忘内容不能通过标题、开头或邻接重新出现。
- [x] 缩短卡片元信息，保留原角色、明确Speaker、说话日期及其非事件日期含义、范围与还有上下文的提示。不得将assistant角色一概降权。

### B．Query、导航路由与观测

- [x] 完整记录词法／向量融合候选，移除仅前48的观测盲区。
- [x] episode是直接阅读入口，note是指向支持原文的导航入口。按命中入口轮流提出未读原文；一个note不得一次把全部支持塞满候选。不将note分数冒充每段原文的证据分数。
- [x] 先保留独立入口，再把来源反链与真正邻接作为有标记的解释上下文附入剩余阅读预算。原文按ref／精确范围去重，不按整条source_id或向量相似度合并不同事实。
- [x] 合并多条Query时保留分支出处，按各分支轮流提供新入口；首轮选中材料仍可回看，但不永久优先占满补查预算。
- [x] 记录入口、来源路径、可见范围、预算排除、补读、新增可见／采用范围和交付范围，页面可看实际I/O。

### C．Select选择可交付的原文

- [x] 候选正文按原文段落／句子编号；工具仍用扁平positions数组选有序原文单位，不让模型抄写引文或计算字符偏移。
- [x] 首轮可输出最多2条queries及最多4个read_more位置。queries可以来自问题要求或已见实体，表达搜索方向而非编造事实；read_more补充已知来源附近原文。末轮只选positions。
- [x] 输入说明真实top_k和字符交付预算、每个单位的大致成本。选择的来源单位可合并为同一来源卡，保留Select首次选择的卡片顺序，卡内原文按原顺序排列，非连续处明确分隔。
- [x] 确定性装箱不改写事实；按单位而非整张大卡取舍，记录每项超限原因。不得声称预算一致就保证模型总能满足全部任务要求。

### D．轻量Reflection

- [x] 在旧note范围内检索相关背景，再取最多6条；记录实际旧候选与展示文本。新原文不能在旧背景检索前把note挤掉。
- [x] 一次小批生成的目标改为帮助以后定位、区分、共同阅读原文；保留有辨识度的实体、数值和语气。继续最多6条短note、只引本批新原文，避免恢复跨批改写审查。
- [x] 不以单来源／同支持集合直接判重复。新增note是否有益，通过检索和答案对照判断。

### E．有限遗忘确认边界

- [x] 将已接受遗忘指令的确认阶段与Add凭据一起持久化，跨Add／重启可延续；下一条非遗忘用户消息结束该阶段。会话切换不能无意恢复旧确认。
- [x] 对确认阶段的助手消息，模型选择复述已撤销陈述／承诺遗忘的原文单位；这些范围不建立可检索episode。一般知识、其他人信息、混合消息中的无关段落保留。
- [x] 现有历史遗忘仍以来源消息为单位；本轮不将其扩成无限期主题策略或全量细粒度历史改写。这个既有局限单列，不宣称已经实现精确遗忘。新确认消息按范围排除，原文不改写。
- [x] 必要判断或索引失败不提交本次接收／确认状态；同ID重放不重复调用。之后明确的新用户陈述可正常进入记忆。

## 首轮实测后的收敛修订

首轮冻结面板 `reading30-public-r1`：12份完整历史400/400 Add、34/38 Search，Reflection406/420；4次Search为非法位置（其中3次read_more）。直接逐句切分产生120—277个单位，列表编号甚至单独占一个单位，段落与单位的双重编号增加误读。在比例题中两项数值已经可见却被Select排除，不能归因召回。

固定四题的原候选做真实组件对照：短段落、单一编号使可选项降为34—70，四次参数合法；比例题20/100齐，自行车链条25恢复，但头盔120仍缺、家庭活动仍不完整。这只是表达对照，不是完整历史或泛化收益。

据此默认采用以下收敛，不保留逐句Select备用分支：

- **阅读单位**：同一自然段内相邻原句合为约600字符的块，超过600且不可按原句拆开的句子保持完整；段落边界仍保留，不把列表编号单独作为证据。模型只见一套`[N]`编号。
- **遗忘确认**继续使用细粒度原句范围，以保留同消息无关信息；这与阅读块不同的是所需粒度，不是第二种Search方法。
- 工具空列表明确为`[]`，0不合法；无修补、钳位或重试。问题必要部分未被支持时可Query，已有片段缺周围上下文时用read_more；不把有主题讨论当已获得具体事实。
- 第二轮 `reading30-public-r2`重新冻结同一12份历史/400 Add/38题；全部新库，分别报告。上一轮新增的三份记录此时已看过，第二轮不再称未见验证集。

最终本地回归146项及3子测试通过。逐项工程核对与实际语义验收以本轮实施报告为准；首轮失败不能因第二轮成功而移除。
