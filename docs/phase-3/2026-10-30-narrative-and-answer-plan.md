# 模块职责、自然叙事与更强Answer：分析和验证计划

2026-10-30。用户要求从共性机制设计Add/Search改进，并允许提升本地Answer强度。保留5a9146a之后全部未提交工作，不覆盖reading30历史，不改凭据、数据库或部署。正式方法仍用mini/v4；更强Answer仅研究侧。

## 方向与可检验假设

1. **导航的用途是区分和定位原文。** 旧背景已正确呈现但导航仍泛化；16段材料与最多6笔记不意味着要求压进全部事实。设计小批择要、同一事件的自然叙事、只引用新原文；明确不记全也不会丢掉原文。先检验提示能否减少超额条目及泛化，不增加审查循环或新字段。
2. **检索目标是支持当前任务，而不只是主题相近。** 列表、比较、总量和冲突需要互补证据；首轮只有部分可见材料。提示明确“已知什么、还缺哪类证据、继续找什么”的实际职责，不强制输出长分析。更进一步的候选续页/有方向查询应围绕已检索未读材料和实际缺口设计，不预设某题答案、不默认强制两轮。
3. **来源可追溯和模型可读是不同展示责任。** 模型只需容易识别的选择标签、原文、主体与时间；offset、稳定哈希、索引路径是审计依据。固定材料比较旧视图、新自然提示、精简视图，检查非法0是否减少；仅能得到局部证据，不能把一次合法归因某个字符。
4. **Answer能力不应成为记忆研究的混淆变量。** 固定同一Search结果，比较旧mini、mini+新提示、较强模型+旧提示、较强模型+新提示。不把换模型造成的正确数增长当作Add/Search进步。声明普通推断与个人事实补造的边界，明确时间锚点、条件和任务完成要求。

## Answer实施约束

候选为GPT-5.4，目标是可用且适度提升推理强度，不是追逐最新型号；先验证再设默认。Chat Completions属于该模型支持接口，Answer单轮无工具续接；无需为此引入复杂Agent。推理预算和输出容量足够、单次期限有界，报告实际token与耗时。新实验身份独立，既有模型响应和原始文件不能改写。

提示使用自然语言清楚表达职责，条件和来源优先；不按公开题名注入提示、不传gold、不补造个人经历。日期推断保留原精度；聚合先区分不同事件和重复描述；建议、可能性与既成事实分开。更强模型输出也要核对是否真的有证据支持。

## 成功标准

Answer可调用、输入完整、模型配置可追溯、旧档案不变、回归通过；强模型仍必须说明证据不足。Add/Search分析要给出“现象→模块职责→机制假设→对照→取舍”的链条，不能通过堆约束或单题参数获得假改善。若组件没有改善，就保留负结果并修订设计，不引入默认关闭生产分支。

## 下一轮 Add/Search 执行方案（原始设计，已由后续执行计划落实）

状态更新：下列原始清单保留设计时记录，逐项实施与真实验证以[continuation执行计划](2026-10-30-reading-continuation-execution.md)和[核对报告](../doing/2026-10-30-reading-continuation-implementation.md)为准。单一引用、连续阅读块、未读候选续接已经默认实施，18完整历史61题已完成；语义质量仍有明确缺口。

### P0：单一可操作引用与自然模型视图

- [ ] 将模型视图与审计视图拆成明确的渲染职责。模型只显示本次局部编号、语义标签、真实标题/原文锚点、角色/说话时间及原文；稳定ref、全局入库序号、字符偏移仍在账本与观测中。不删原文中本来存在的数字或字段。
- [ ] Reflection与Select共用局部编号到来源范围的确定性映射；结果验证仍严格，不把非法编号自动猜成合法来源。引用语义名称与必要说明仍保留。
- [ ] 整理提示以“择要建立可定位的导航”为任务，不要求覆盖全部材料。正文尽量沿用原文称谓、动作与限定，标题负责简洁概括；不增加人物关系类型或审查循环。
- [ ] 验证：固定失败与正常输入；另加不同素材的同名/泛称/第三人称对照。检查编号合法、归属与语气、实际链接、重复导航；不能用较高完成率掩盖语义补造。新库完整历史验证后才能宣布生产收益。

无需迁移原文库或embedding模型；渲染变化本身不改变存储身份。若随后改变索引切段，则需独立版本与新库，不能混在纯展示修订中。

### P1：先减少无意义选择，再让阅读真正前进

- [ ] 阅读单位合并同一来源可读区域内的相邻短段，保留内部原文和换行。显式标题、来源及遗忘排除边界必须保留；跨角色的邻接材料仍分别呈现。不能把网页按钮黑名单当通用方案。
- [ ] 同时记录可选单位数、有效原文字符数与模型输入字符数，避免只看总窗口够大。先离线比较单位粒度分布及引用保真，再进行固定输入Select；不能以合并单位后“选得少了”当语义更好。
- [ ] 保留Query得到但尚未展开的候选队列。首轮输入增加有界的未读References目录（短标签与命中片段），模型可选择其中需要读的引用。此处是新增的候选续读能力；与既有 `read_more` 的来源相邻补读分清参数空间，避免再次混用编号。
- [ ] 继续查询仍最多2条、阅读仍最多两轮。第二轮先呈现真正新增材料，首轮选中的原文范围独立携带，再合并Select；相同query/已读范围无新增则不重复展开。程序负责去重、预算和观测，模型负责判断相关性和缺口。
- [ ] 提示用简短的任务说明表达：留下哪些原文能支持回答；已够则停止；若不够，读哪份现有材料或寻找哪类缺失事实。不要求每题写覆盖清单、不默认触发第二轮。当前“普遍补读”的实验提示不进入生产。
- [ ] 验证分别覆盖简单充分、已召回未读、需要相邻限定、真正未召回、集合与长文任务；观察每次动作新增了什么，选中何处，哪些必要事实最终交付。不得让某个价格、项目名或题型特判进入逻辑。

候选续读的具体字段与原文菜单分组应在实现前做一次固定输入原型核查；采用引用标签可清楚区分候选与已读单位的最简接口，不再加独立计划器或无界loop。
