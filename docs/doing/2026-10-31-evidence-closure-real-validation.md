## 按案例检查完整链路

### r16：闭合能保住代词的邻接语境，但装箱仍会竞争名额

Search 找到了正确的宠物时间事实（命中率@5 为 1），但三个目标原文只有一个进入评估匹配。最终 GPT-5.4 能正确比较 Susie 的“两年”和 Seraphim 的“去年”，回答为 Seraphim 更新；这说明相邻语境闭合对短时间表达有实际帮助。

不过最终装箱有 6 个 `top_k` 省略，闭合记录为 6 个，部分相邻 episode 闭合也出现在装箱竞争范围内。闭合修复解决的是“选中句子缺前文”，没有解决“多组证据共同交付”的预算问题。

### r17：任务形状提示没有让检索主动寻找补集

“除了瑜伽还有什么”活动运行成功，首个命中正确（MRR 1、hit@5 1），但五个目标只有一个被召回。真实 Select 输入包含补集提示，可观测的 `queries` 仍为空；候选集中瑜伽主题占据主要位置，没有形成针对其它活动的检索分支。

GPT-5.4 回答列出跑步、冥想、工作坊、社区和亲友，部分来自返回上下文，部分是模型对不完整证据的整理。它不能证明 Search 已经找到骑车/看展、冲浪和园艺等互补事实。当前提示改善了模型检查入口，却没有产生检索覆盖。

### r18：续读和闭合可工作，但对象类型仍被主题相似性混淆

运行产生两轮 Select：第一轮有一个续读请求，第二轮完成交付；最终装箱无预算省略，闭合记录 2 个。五个目标中两个被召回，说明“问句与回答共同成立”的证据仍未完整进入候选。

GPT-5.4 只回答 Tim 喜欢《指环王》和《星战》，并把 Harry Potter 保留为“泛粉丝而非明确电影偏好”。该判断在当前交付证据下是谨慎的，但题目要求区分电影喜好，说明 Search 没有把电影对象、对应问句和本人回答作为共同证据组交付。闭合能够补邻句，不能替代对象类型和关系的检索。

### r19：规则被召回，当前实例边界仍未成为可见语境

这是一个没有评估侧证据目标的 CL-bench 研究样本，因此只报告运行轨迹和 Answer，不计算 recall。四个 Add 和两轮 Select 都成功，最终返回 5 组证据，闭合记录 5 个。

GPT-5.4 正确计算了每月 65 美元的 loss of support、435 美元的余款和 2,000 美元利息，但把“同一公司”直接套成上一轮的 wrongful-death settlement。它随后加了条件说明，却仍没有满足“不能假定新实例性质、435 美元的税务性质取决于伤害来源”的要求。这里的问题不是 API 失败，也不是 Answer 模型不够强，而是 Search 交付了规则和旧实例结论，却没有清楚分开“规则”“旧实例”“本次实例未给出的条件”。

## 这轮对方法的结论

1. **P0 闭合已经真实生效，但作用范围有限。** 它保存了原文、记录 `model_selected` 与 `context_closure`，对 r16 的时间比较有帮助；闭合来源是可审计的，不能把它当成完整证据集合。
2. **任务形状提示不是查询扩展。** r17 的补集问题和 r18 的对象类型问题都没有生成新的 Query 分支；只在 Select 提示中描述“应该找什么”不足以改变 BM25/向量候选集合。
3. **证据缺失主要发生在 Query/候选集合和 Select 的共同证据组织处。** r16–r18 都是 hit@5 为 1 但 evidence recall 只有 0.2–0.4，说明“有一个相关入口”不能代表回答所需的证据链已齐。当前 24 入口、5 组交付和相邻闭合之间仍有预算耦合。
4. **Reflection 近似去重没有造成协议损失，但质量收益尚未由这四题证明。** 四次运行 duplicate_rate 均为 0，Reflection 没有 schema/来源错误；这只是说明保守控制稳定，不代表导航 note 已经覆盖互补事实或清楚区分规则与实例。
5. **更强 Answer 只能改善可读性和计算，不能补齐 Search 没交付的事实。** r16 结果正确，r17/r18 部分正确，r19 仍发生适用范围误用。后续应优先改善 Search 的证据集合与来源边界，再用 Answer 做独立诊断。

## 下一步设计方向

下一轮不为 r17、r18 或 r19 写答案特例，而是从这些现象抽象出三个可验证的改动：

- 在现有 Query→Select 结构内加入**有限的证据槽表达**：由问题提取主体、对象类型、属性/时间、排除条件和适用范围的查询表达，合并所有分支候选后只调用一次 Select；没有新候选时明确记录“没有增量”，不把提示词当成召回。
- 将 Select 的输出从“若干独立片段”提升为**共同证据组**：问句/回答、对象/属性、规则/实例等有实际邻接或来源关系的单位共享组预算；跨 episode 的闭合要标明是解释性附件，不能静默挤掉另一条核心证据。
- 在模型可见叙事中显式区分**规则、历史实例、本次输入条件和未知条件**。这是一种来源语义和适用范围的呈现，不是把某个数据集答案写入提示词；需要用新的多数据集运行检查它是否降低跨实例套用。

这三项先通过合成 fixture 和可观测账本验证输入/输出，再用新的完整公开历史运行。当前真实结果支持继续设计与验证，但不支持宣布整体准确率提升或把四题当作泛化成绩。
