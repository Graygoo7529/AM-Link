## 已核对的硬约束

| 项目 | 主办方约束 | 当前实现 |
| --- | --- | --- |
| Add 成功语义 | HTTP 200 返回前必须完成持久化并可被 Search 立即找到 | `done`，raw event、working memory、FTS 在同一 SQLite 事务提交 |
| Add 响应 | `success`、`request_id`、`user_id`、`session_id`，不返回异步 task | `done` |
| Search 请求 | `query`、`user_id`、`top_k`，可带 `options` | `done`，服务端上限 100 |
| Search 响应 | `data` 数组；每项至少有稳定 `id` 和非空 `content`；允许空数组 | `done` |
| Search 语义 | 返回记忆证据，不生成最终答案 | `done` |
| 隔离 | 只能检索相同 `user_id` 的记忆 | `done`，SQLite、FTS 和 Markdown 均携带用户范围 |
| 鉴权 | Token、Bearer、X-Api-Key；Health 可公开 | `done` |
| 模型 | Full 清单要求提交的 memory system 在 Add 和 Search 使用 `gpt-4o-mini` | `done`，默认和正式配置双路径固定模型；非官方模型仅允许显式本地调试开关 |
| Full top_k | 100 | `done` |
| Full 时限 | 官方公开仓库披露为 72 小时 | 由主办方客户端控制；本服务尚未完成压力验证 |
| Add 运行参数 | 默认 64 workers、20-message chunks、1200 秒 HTTP timeout | 协议兼容；尚未完成 64 并发压力报告 |
| Search 运行参数 | 默认 32 workers、1200 秒 HTTP timeout、重试和失败 requeue | 服务可重试但尚未完成官方客户端回放 |
| 代码提交 | 公开仓库、Docker 构建/启动说明、固定版本，不提交 Eval Key | Dockerfile、README、依赖已完成；尚无公开仓库 commit |
| 自部署 API | 公网稳定地址、鉴权、按要求保持至少 30 天 | 尚未部署 |
| 数据留存 | 评测数据及派生副本仅用于当前任务，完成后 30 天内删除 | `todo`，需补删除与清理流程 |

## 协议实现路径

当前服务路径为：

```text
GET  /health
POST /v1/memory/add
POST /v1/memory/search
```

正式提交前仍需用主办方 Smoke 客户端确认其配置的路径拼接方式；如客户端要求不同前缀，只增加兼容路由，不改变请求/响应 schema。

## 已确认的完整提交清单

赛事官网 Full checklist 共 8 项：

1. Smoke 已通过；
2. API contract 正确；
3. Add/Search 使用 `gpt-4o-mini`；
4. 自部署运行至少 30 天稳定；
5. README/运行说明完整；
6. 原创工作和复用来源披露；
7. 不是重复或低质量占位提交；
8. 不存在硬编码、数据泄漏、提示词注入、人工答题或结果操纵。
