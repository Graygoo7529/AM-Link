## 当前运行实例

当前本地增强实例启动于 `http://127.0.0.1:18085`，真实 HTTP Health/Add/Search 已通过。Add 约 10.2 秒、Search 约 4.7 秒，Top-1 返回正确的 Qingdao 事实；数据库包含 2 fact、3 entity、2 concept、7 links 和 9 个 512 维向量，maintenance/job 均为 `completed`。运行配置为：

```text
AML_AUTH_SCHEME=none
AML_DB_PATH=B:\tmp\aml-memory-full-live.db
AML_MARKDOWN_VIEW_DIR=B:\tmp\aml-memory-full-live-md
AML_LLM_ENABLED=true
AML_LLM_MODEL=gpt-4o-mini
OPENAI_BASE_URL=https://api.zhizengzeng.com/v1
AML_EMBEDDING_ENABLED=true
AML_EMBEDDING_MODEL=embedding-3
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4
```

两个提供方 Key 只存在于 Uvicorn 进程环境中，未写入仓库、SQLite、Markdown 或日志。该实例无鉴权且只监听 loopback，仅适合本机测试，不适合提交或公网部署。

## 残余风险

1. 正式 Full 必须启用 `AML_LLM_ENABLED=true`；默认关闭模式只适合 Smoke/降级。
2. 微信公众号正文无法从当前网络环境读取，需人工确认是否有官网未列出的补充规则。
3. 增强链路尚未用官方公开数据做 recall@k、时间、多跳和成本校准。
4. SQLite 单文件适合单容器；多实例部署前必须迁移共享事务存储和共享向量索引。
5. FastAPI TestClient 当前有 Starlette/httpx 兼容性 warning，不影响运行测试；正式部署不使用 TestClient。
6. 智增增已返回声明为 `gpt-4o-mini` 的响应，但仍需核验代理的数据留存、账单上限和 72 小时评测容量；局部回放出现 1/5 maintenance 偶发 `ValueError`，需扩大样本统计失败率。
