# 一期设计理念

我们要把跨会话经历整理成可追溯的记忆，让检索提供足够可靠的证据，最终回答交给统一评测模型。

1. **原始经历是依据。** 完整保留说话者、消息顺序、会话和事件时间；摘要与索引都能从原文重建，不能用模型总结替代原文。
2. **先记住，再整理。** 新内容先可靠写入并可检索，再提取事实、实体和主题。近期工作记忆帮助增量整理，避免每次重读全部历史。
3. **记忆通过来源和关系相连。** 一个事实能找到其原文，也能关联到人物、主题及相关事件。链接的价值是帮助找到证据，而非为了把所有内容连成复杂图。
4. **变化也是记忆。** 新状态不抹去旧状态；区分事件发生时间与系统写入时间，回答“现在”和“当时”需要不同证据。
5. **词面与语义互补。** 词面检索保留姓名、数字和否定词；语义检索处理同义表达。关系扩展有助于找齐分散证据，但必须限制噪声。
6. **先查看，再修改。** 模型只根据已读取的同一用户记忆进行整理，不凭空更新未知事实。每个派生结论必须有来源。
7. **检索只交付证据。** 结果按相关性排序并减少重复，保留完成推理所需的不同证据；不能直接生成答案。
8. **隔离与成本是设计边界。** 用户之间完全隔离；一次请求的工作量和模型开销可解释、可停止。复杂机制只有经实验有收益才保留。

这些思想来自作者自己的 TinySoul-Agent。比赛版提炼其“工作记忆、稳定链接、先检索再整理”的机制，没有照搬完整 Agent 生命周期。

一期曾把失败后的自动补偿理解为可靠性保障，实测却暴露出持续费用与成功语义不清的问题。二期保留以上记忆思想，重新设计失败处理，不延续后台持续补偿。
